# Rising bit error rate from a ground-plane void

A high-speed net degraded with a rising bit error rate and jitter. The symptom resembled coupling, but the neighbouring traces were well separated. The cause was a void in the reference plane beneath the trace that severed the low-inductance return path and forced the return current to spread, raising effective inductance and slowing the rise time. The fix filled the plane void and routed the return path continuously under the signal. Trace-to-trace spacing was not the problem.
