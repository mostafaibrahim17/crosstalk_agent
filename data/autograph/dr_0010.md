# Jitter from a return-path discontinuity at a layer change

A high-speed signal showed frequency variation and jitter after a layer transition. It read like coupling, but the adjacent nets were spaced within the guideline. The real cause was a return-path discontinuity: the signal changed reference planes with no stitching via nearby, so the return current detoured and raised loop inductance. The fix added a ground stitching via at the transition to give the return current a continuous path. Spacing was fine.
