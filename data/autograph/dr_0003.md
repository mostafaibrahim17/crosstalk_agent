# Display lane errors from a long parallel run, fixed by reroute

A display serial lane showed frequency variation and a climbing bit error rate. It shared a layer with an unrelated high-speed signal, and the two ran parallel for roughly 52 mm at a gap near 0.35 mm, inside the separation the design guideline recommends for the trace width in use. The coupling was far-end crosstalk over the long adjacent run. Board area near the victim was too tight for a guard trace, so the fix moved the aggressor to a different layer with an intact reference plane between the two, cutting the parallel overlap to almost nothing. The errors cleared.
