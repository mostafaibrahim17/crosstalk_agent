# Eye closure from a via stub, not from coupling

A serial lane showed eye-diagram closure and a rising bit error rate that looked like inter-lane crosstalk. No close parallel aggressor was present. The cause was a via stub left by a layer transition; at the lane's data rate the stub reflected and radiated, distorting the waveform. The fix back-drilled the stub and reduced the number of layer changes. Opening the spacing to neighbours would not have changed the eye.
