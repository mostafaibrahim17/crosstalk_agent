# Guard trace tames clock-to-data coupling on a shared layer

A high-speed data lane developed timing jitter and eye-diagram closure where a clock lane from a different interface ran beside it. The two were unrelated nets that simply shared the bottom copper layer for a long span. Because a clock switches continuously with fast edges, it was a strong aggressor, and the behaviour matched near-end crosstalk over the run. The parallel overlap was close to 44 mm at an edge-to-edge gap around 0.4 mm, inside the two-trace-width separation the routing guideline calls for. Board area did not allow a full reroute, so the fix added a grounded guard trace with stitching vias between the clock and the data lane and opened the spacing where it could. The jitter dropped and the eye reopened.
